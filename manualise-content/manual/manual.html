    3. About the sensor
    3.1. Design and function
    The sensor is an external sensor that replaces the valve cap of the tire. The sensor can be used on all truck and bus tire brands. The sensor provides accurate tire pressure readings which can be accessed via the Hand-Held Tool or the ContiConnect" platform. Real-time digital reading can significantly reduce downtime by keeping all tires at the correct pressure at all times. The product has excellent scalability and is especially suitable for use in big fleets.

    6. Installation
    This chapter contains important information and instructions about installing the sensor.
    6.1. Delivery scope
    1. Remove the packaging and all packaging material.
    2. Check that the package has the following content:
    1×
    Valve Cap Sensor
    3. Check the sensor for visual damage.
    _ NOTICE _
    Risk of improper functioning of the sensor. Never install a damaged sensor. Please contact your supplier in case of a damaged sensor.
    6.2. Preparation
    1. Remove the valve cap from the tire.
    2. Measure the pressure of the tire with a tire pressure gauge.
    3. If necessary, adjust the tire pressure using an air compressor to the required PSI indicated on the tire or the vehicle.
    Leave the valve caps from the tires in preparation for installing the sensor.
    6.3. Installing the sensor
    1. Screw the sensor onto the valve of the tire until you hear a brief hiss.
    The brief hiss indicates a correct seal between the sensor and the valve of the tire.
    2. Screw the sensor an additional 90 – 180 degrees to completely seal the valve of the tire.
    The sensor is now installed and ready to be configured in the ContiConnect" system.
    7. Operation
    This chapter describes the main operational procedures of the sensor.
    Please refer to the HHT user manual for more in depth information about the user interface of the HHT.
    7.1. Reading the measured data
    You need a HHT for reading the measured data of the sensor. If you do not yet have an HHT, please contact your supplier.
    1. Switch on the HHT and wait until you see the main menu.
    2. Select Tire Sensor from the main menu.
    3. Select Check all tires in the Tire Sensor menu.
    4. Enter the vehicle name or identification number that is already set up in the ContiConnect" platform.
    If you have not yet set up your ContiConnect" platform, please contact your supplier.
    5. Set the vehicle type.
    6. Set the axle configuration to match the vehicle:
    7. Use the ← and → arrow keys to select an axis. Press the ↵ key to confirm.
    8. Use the ↑ and ↓ arrow keys to change the tire configuration of the selected axle. Press the ↵ key to confirm.
    Go to the tire that is indicated with brackets on the HHT screen.
    9. Change the user setting to Valve Sensor using the ← and → arrow keys. Press the ↵ key to confirm.
    10. Check if the sensor ID displayed on the HHT corresponds with the sensor ID on the sensor.
    11. Scan the sensor with the top left area of the HHT. Follow the instructions on the HHT screen.
    The HHT vibrates when a sensor is detected.
    12. The HHT displays the current pressure of the tire as measured by the sensor.
    13. Repeat step 7 – 10 for all tire positions equipped with a sensor.
    Press ESC on the HHT to skip a tire if no sensor is installed.
    The HHT screen displays Report file stored when all tire positions have been checked.
    14. Press the ↵ key to proceed.
    The HHT screen displays an overview of the vehicle tire configuration and the measured tire pressure.
    If the HHT screen displays a ! on a tire, it indicates that the sensor is loose or defective. Please refer to §7 for troubleshooting.
    15. Press and hold the ESC key for 5 seconds to exit the menu. Select Yes using the ← and → arrow keys. Press the ↵ key to confirm.
    The data is now ready to be transmitted to the ContiConnect" platform.
    Please refer to the HHT user manual for more information about transmitting data from the HHT to the ContiConnect" platform.
    8. Troubleshooting
    Problem
    Possible cause
    Possible solution

    Select Valve Sensor on the HHT before scanning the sensor.
    The HHT screen displays a ! on a tire.
    The sensor is loose from the tire valve.
    1. Unscrew the sensor from the tire valve.
    2. Scan the sensor with the HHT to check if the sensor is defective.

    3. Follow the instructions in §6.3. to reinstall the sensor.
    The sensor is defective.
    Please contact your supplier.

    3. Acerca do sensor

    O sensor é um sensor externo que substitui a tampa da válvula do pneu. O sensor pode ser usado em todas as marcas de pneus de camiões e autocarros. O produto tem uma excelente escalabilidade e é especialmente indicado para a utilização em grandes frotas.

    1. Remova a embalagem e todo o material de embalamento.
    2. Verifique se a embalagem traz os seguintes materiais:
    1×
    Sensor da tampa da válvula
    3. Verifique visualmente se o sensor apresenta danos.
    _ AVISO _
    Risco de mau funcionamento do sensor. Nunca instale um sensor danificado. Contacte o seu fornecedor no caso de um sensor danificado.
    6.2. Preparação
    1. Remova a tampa da válvula do pneu.
    2. Meça a pressão do pneu com um manómetro de pressão de pneus.
    3. Se for necessário, ajuste a pressão do pneu com um compressor de ar com a PSI indicada no pneu ou no veículo.
    Retire as tampas das válvulas dos pneus em preparação para instalar o sensor.
    6.3. Instalar o sensor
    1. Enrosque o sensor na válvula até ouvir um pequeno silvo.
    O pequeno silvo indica a perfeita vedação entre o sensor e a válvula do pneu.
    2. Enrosque o sensor mais 90-180 graus para vedar completamente a válvula do pneu.
    O sensor está agora instalado e pronto para ser configurado no sistema ContiConnect"
    7. Operação
    Este capítulo descreve os principais procedimentos operacionais do sensor.
    Consulte o manual do utilizador da HHT para obter informações mais detalhadas sobre a interface do utilizador da HHT.
    7.1. Leitura dos dados medidos
    É necessária uma HHT para ler os dados de medição do sensor. Se ainda não tem uma HHT, contacte o seu fornecedor.
    1. Ligue a HHT e aguarde até ver o menu principal.
    2. No menu principal, selecione Tire Sensor
    3. No menu do Tire Sensor, selecione Check all tires.
    4. Introduza o nome ou número de identificação do veículo que já está configurado na plataforma ContiConnect".
    Se ainda não configurou a sua plataforma ContiConnectTM, contacte o seu fornecedor.
    5. Defina o tipo de veículo.
    6. Defina a configuração do eixo de acordo com o veículo:
    7. Use as teclas de seta ← e → para selecionar um eixo. Prima a tecla ↵ para confirmar.
    8. Use as teclas de seta ↑ e ↓ para alterar a configuração do pneu ou o eixo selecionado. Prima a tecla ↵ para confirmar.
    Dirija-se ao pneu que está indicado entre parênteses no ecrã da HHT.
    9. Altere a configuração do utilizador para “Válvula”, usando as teclas de seta ← e →. Prima a tecla ↵ para confirmar.
    10. Verifique se a ID do sensor apresentada na HHT corresponde à ID do sensor no sensor.
    11. Leia o sensor com área superior esquerda da HHT. Siga as instruções no ecrã da HHT.
    A HHT vibra, quando é detetado um sensor.
    12. A HHT apresenta a pressão atual do pneu de acordo com a medição do sensor.
    13. Repita os passos 7-10 para todas as posições de pneus equipadas com um sensor.
    Prima ESC na HHT para avançar um pneu se o mesmo não tiver um sensor instalado.
    Quando todas as posições tiverem sido verificadas, o ecrã da HHT apresenta “Ficheiro do relatório guardado”.
    14. Prima a tecla ↵ para continuar.
    O ecrã da HHT apresenta uma visão geral da configuração do pneu do veículo e a pressão do pneu medida.
    Se o ecrã da HHT apresenta um ! num pneu, isso indica que o sensor está solto ou com defeito. Consulte o §8 para resolução de problemas.
    15. Prima e mantenha premida a tecla ESC, durante 5 segundos, para sair do menu. Selecione Yes, usando as teclas de seta ← e →. Prima a tecla ↵ para confirmar.
    Os dados estão agora prontos para serem transmitidos para a plataforma ContiConnect".
    Consulte o manual do utilizador da HHT para mais informações sobre a transmissão de dados da HHT para a plataforma ContiConnect".

    1. Desenrosque o sensor da válvula do pneu.
    2. Leia o sensor com a HHT para verificar se o sensor está com defeito.
    Se a HHT apresentar dados sobre o pneu, o sensor não apresenta defeitos e pode ser reinstalado.
    3. Siga as instruções no §6.3 para reinstalar o sensor.

    10. Desativação
    1. Desenrosque o sensor da válvula do pneu.
    2. Enrosque uma nova tampa da válvula na válvula do pneu para prevenir a acumulação de sujidade e de resíduos.
    3. Elimine o sensor de acordo com as instruções.
    Consulte o §11 para informações detalhadas sobre a eliminação.
    11. Eliminação
    O produto são deve ser eliminado como um resíduo indiferenciado, devendo ser enviado para instalações de recolha seletiva para recuperação e reciclagem. Elimine o material de acordo com os regulamentos locais.
